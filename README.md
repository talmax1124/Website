# Obsessions Wheels

Site for [Obsessions Wheels LLC](https://obsessionswheels.com) in Kissimmee, Florida — OEM originals, replica wheels, fitment help, financing, and nationwide shipping.

## Stack

- TanStack Start + Vite + React
- Tailwind CSS
- GSAP + Lenis
- LightWidget Instagram feed (`@wheelprofl`)
- FormSubmit contact form

## Develop

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```

## Deploy

This rewrite targets **Vercel** (Nitro / TanStack Start). It is not the previous Eleventy + Netlify build.

Set the production domain to `obsessionswheels.com` after connecting the repo to Vercel.
